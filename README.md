# ANLI Agency

Site institucional da ANLI Agency, desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

## Build de produção

```bash
pnpm build
pnpm preview
```

O projeto está configurado para deploy na Vercel com `pnpm run build` e saída em `dist/`.
